# Projector Product Line — Supplemental Terminology

**Inherits:** all entries in [`glossaries/approved-terms.md`](../glossaries/approved-terms.md)
apply to projector documentation. Terms below are additions specific to this
product line.

**Approval:** same [approval process](../workflows/approval-process.md), with
the projector SME seated on the review board.

---

### throw distance (n.)
**Definition:** Distance from the projector lens to the screen surface.
**Use:** Always paired with the resulting image size in the same sentence or
table row. Never state one without the other — this pairing is the single
most common installation support question.
**Forbidden:** projection distance, installation distance
**DNT:** No
**Context:** "At a *throw distance* of 3 m, the projected image measures
approximately 100 inches diagonally."

### keystone correction (n.)
**Definition:** Digital or optical adjustment compensating for trapezoidal
image distortion when the projector is not perpendicular to the screen.
**Use:** Specify digital vs. optical where the distinction matters; digital
correction reduces effective resolution and documents must say so.
**Forbidden:** angle adjustment, trapezoid fix, corner correction
**DNT:** No
**Warning binding:** any procedure involving digital keystone must carry the
resolution-loss note. This is enforced by the style checklist, not left to
writer discretion.

### lamp hours (n.)
**Usage note:** Retired for LED and laser light sources — see
[`../glossaries/deprecated-terms.md`](../glossaries/deprecated-terms.md).

### light source hours (n.)
**Definition:** Cumulative operating time of the illumination source (lamp,
LED, or laser).
**Use:** Replaces "lamp hours" across all light-source types so one term
covers the product range.
**Forbidden:** lamp timer, usage time, operating hours
**DNT:** No

### projection offset (n.)
**Definition:** Vertical position of the image relative to the lens axis,
expressed as a percentage of image height.
**Use:** Numerically ("Projection offset: 110% ±5%"); never described
prose-only, because installers compute mounting height from this value.
**Forbidden:** image offset, lens shift range
**DNT:** No
**Note:** "Lens shift" is a *different* feature (optical image displacement)
and the two terms are never interchangeable.

### ceiling mount mode (n.)
**Definition:** Installation configuration with the unit inverted and image
flipped 180°.
**Use:** Always "mount mode," never "install mode" — reserved phrase.
**Forbidden:** upside-down mode, inverted installation
**DNT:** No

### standby power (n.)
**Definition:** Electrical consumption in standby mode, measured per
regulatory test conditions.
**Use:** Always reported with the measurement standard cited; raw numbers
without the standard are banned because jurisdictions test differently.
**Forbidden:** idle power, sleep consumption
**DNT:** No
