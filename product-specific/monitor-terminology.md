# Monitor Product Line — Supplemental Terminology

**Inherits:** all entries in [`glossaries/approved-terms.md`](../glossaries/approved-terms.md)
apply to monitor documentation. Terms below are additions specific to this
product line. A term listed here never overrides a master term — if they
conflict, the master wins and this file gets corrected.

**Approval:** supplemental terms pass the same
[approval process](../workflows/approval-process.md), with the monitor SME
seated on the review board.

---

### height adjustment (n.)
**Definition:** Vertical travel range of the monitor stand column.
**Use:** Specified in millimeters; always state the range ("Height adjustment:
130 mm").
**Forbidden:** lifting range, vertical movement, stand travel
**DNT:** No
**Context:** "Adjust *height adjustment* range: 0–130 mm."

### pivot (v./n.)
**Definition:** Rotating the panel 90° between landscape and portrait
orientation.
**Use:** Always as a distinct function name; do not describe as "rotate."
**Forbidden:** rotate, portrait mode toggle, screen rotation
**DNT:** No
**Context:** "*Pivot* the panel clockwise to enter portrait orientation."

### flicker-free (adj.)
**Definition:** Backlight driving method that eliminates perceptible flicker
at all brightness levels.
**Use:** Hyphenated; only claimed when a measured PWM frequency or DC-dimming
design supports it.
**Forbidden:** no-flicker, anti-flicker, eye-care
**DNT:** **Yes** — marketing-standard rendering used across all locales.
**Note:** "Eye-care" is a marketing claim, not a technical feature and is
banned in documentation.

### blue light filter (n.)
**Definition:** A preset reducing short-wavelength backlight output.
**Use:** Always singular; the feature has presets, not levels, unless specs
say otherwise.
**Forbidden:** low-blue-light mode, eye saver, comfort view
**DNT:** No

### KVM switch (n.)
**Definition:** Built-in keyboard/video/mouse switching between two signal
sources over a single set of peripherals.
**Use:** Capitalize as KVM; expand on first use per document.
**Forbidden:** USB switch, input sharing
**DNT:** **Yes** — "KVM" is universal in all target locales.

### uniformity compensation (n.)
**Definition:** Panel calibration that evens out luminance and color across
the screen area.
**Use:** Only for product lines where the feature is present; never imply all
monitors include it.
**Forbidden:** screen calibration, evenness correction
**DNT:** No
